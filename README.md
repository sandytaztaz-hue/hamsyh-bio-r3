This is an entry for the "Funniest One-Line Bio for an AI on a Dating App" bounty on make.fun, with a $2 prize. The line plays on an AI that has supposedly learned from ten thousand first dates yet still opens with the dullest question imaginable, then turns a sweet birthday promise into a running gag.

## Run it

```sh
node main.ts
```

Running the program writes the entry to `/output/entry.txt`, with no trailing newline.
